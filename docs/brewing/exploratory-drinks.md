# Exploratory Drinks — journal + stash (the drinks lane's working surface)

> **What this is:** the living record for the exploratory drinks lane — the deliberately LOW-RIGOR,
> for-fun, cross-discipline lane established 2026-08-27 (charter + wishlist + technique reference:
> [docs/features/exploratory-drinks-lane-2026-08-27.md](docs/features/exploratory-drinks-lane-2026-08-27.md)).
> NOT research machinery: no protocol docs, no Coordinator/Assistant roles, no hypothesis ledgers,
> no push_brew obligation. A drinks session reads this doc, helps build + adjust the drink, appends
> a journal entry + any stash changes, and commits. That's the whole loop.
>
> **Graduation paths:** a keeper recipe worth durable archival → deliberate one-off decision (brew-row
> vs staying here). A durable repeatable finding worth building on → research roadmap via talk-through.
> A canon-touching question (vocabulary, a modifier candidate, a serving-form question) → grilling queue.
> After ~2-3 sessions, if the session shape stabilizes → candidate `/drinks` skill (per
> prototype-before-generalizing; this doc is the substrate a future skill would compose over).
>
> **Claude-Code-native; deliberately NOT MCP-registered** (matches the research-projects convention).
